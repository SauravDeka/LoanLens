# LoanLens — Loan Analytics & Risk Assessment

LoanLens is a web-based loan analytics and risk assessment project built with **Python and Flask**.

The application analyzes a **predefined loan approval dataset included in this repository** and turns the data into KPIs, approval-pattern analysis, risk analysis, interactive visualizations, and a supporting machine-learning prediction feature.

> **Project focus:** Data analytics and risk assessment come first. The machine-learning model is a supporting component.

## What LoanLens Does

LoanLens helps explore the loan approval dataset through:

- Overview KPIs
- Dataset information
- Approval-rate analysis
- Credit score and DTI analysis
- Income and loan-amount analysis
- Employment and loan-purpose comparisons
- Risk-factor analysis
- Combined risk segmentation
- Interactive Plotly visualizations
- Supporting loan approval prediction
- Model performance evaluation
