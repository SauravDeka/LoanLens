# LoanLens — Loan Analytics & Risk Assessment

🚀 **[Live Demo](https://loanlens-1-xo0t.onrender.com)**

LoanLens is a web-based loan analytics and risk assessment project built with **Python and Flask**.

The application analyzes a **predefined loan approval dataset included in this repository** and transforms the data into KPIs, approval-pattern analysis, risk analysis, interactive visualizations, and a supporting machine-learning prediction feature.

> **Project focus:** Data analytics and risk assessment are the primary focus. The machine-learning model is a supporting component.

---

## What LoanLens Does

LoanLens explores the loan approval dataset through:

- Overview KPIs
- Dataset information
- Approval-rate analysis
- Credit Score analysis
- DTI Ratio analysis
- Income analysis
- Loan Amount analysis
- Employment Status comparison
- Loan Purpose comparison
- Risk-factor analysis
- Combined risk analysis
- Interactive Plotly visualizations
- Supporting loan approval prediction
- Model performance evaluation
